# 0001. ADR 도입

- 상태: Accepted
- 날짜: 2026-06-11

## 맥락

주요 기술 결정(상태 관리, 라우팅, API 전략, 인증 등)의 배경이 산문 문서(CLAUDE.md, README)에
흩어져 있어, 결정의 "왜"와 대안을 추적하기 어렵다.

## 결정

경량 MADR 형식의 ADR 을 `docs/adr/` 에 누적한다. 되돌리기 어렵거나 팀 합의가 필요한 결정은
구현 전/직후에 ADR 로 남긴다. ADR 은 불변 기록이며, 번복 시 새 ADR 로 이전 결정을 Superseded 처리한다.

## 결과

- 합류자가 결정 맥락을 한곳에서 파악한다.
- 같은 논의의 반복을 줄인다.
- 사소한 결정까지 남기는 부담이 있으나, "되돌리기 어려운 것"으로 범위를 한정해 완화한다.
